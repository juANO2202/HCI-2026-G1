# HCI-2026-G1 · Emoción y experiencia de usuario

Repositorio del Grupo 1 (G1) de Interacción Humano-Computador.

**Integrantes:** Juan · Sandro · Shantall · Korayma

## Dinámica del grupo
1. Mostramos **dos interfaces** a la clase y preguntamos: *"¿Cuál les genera mayor confianza y por qué?"*
2. Explicamos la **curva emocional**, los **momentos de verdad** y las **oportunidades de mejora**.
3. Entregamos a los compañeros **una interfaz** para que:
   - identifiquen **6–8 touchpoints**,
   - marquen **mínimo 2 momentos de verdad**,
   - propongan **3 mejoras**.

## Entregables obligatorios en GitHub
- [ ] Curva emocional inicial → `resultados/`
- [ ] Issues con los problemas encontrados → pestaña *Issues*
- [ ] Propuesta corregida → `prototipos/`
- [ ] Comparación antes/después → `resultados/`
